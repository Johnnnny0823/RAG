# 檢索評估

以 [TIPO 種子集](../evaluation/tipo_seed.json) 及 [評估腳本](../scripts/evaluate_search.py) 比較詞彙、向量與混合加重排序。種子集有兩筆查詢與三項相關標註，由 Codex 核對已索引的官方標題或請求項，待人工複核。公開與公告分開評分。同一文件階段和編號的其他版本保留原排行位置，重複命中只計分一次。

- Precision@10 採保守下限，分母固定為 10，未標註項與空位皆不計分。
- Recall@10 與 nDCG@10 只對已標註池計算。未標註文件另列數量，不能據此判為不相關。
- MRR 取首個已知相關文件的倒數排名。標註值 0、1、2 分別表示不相關、部分相關、直接相關。
- 延遲以本機 HTTP 往返計時，包含服務、資料庫及模型。每個模式的 P95 採 nearest rank，少量重複的結果不代表負載上限。
- 原文核對另以 `evaluate_citations.py` 驗證指定版本、字元區間、逐字引文、XPath 及雜湊。硬體耗電及每次查詢成本未量測。

將 `--dataset` 指向人工複核後的同格式資料集即可重跑。應記錄語料批次、標註者、判定依據及模型版本。
