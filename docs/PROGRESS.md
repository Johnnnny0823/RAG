## 先前技術調查驗收條件

驗收可使用不同技術領域的發明構想。智慧冰箱是可替換的例子，專利命中與分析結果取決於實際索引內容。

| 階段 | 要驗證的行為 |
| --- | --- |
| M1 資料 | 合法取得 TIPO 樣本並重跑同批匯入，確認可從資料庫回溯原始檔、文件版本與請求項。分開保存申請案、公開文件及公告文件。法律狀態須有可查證的來源及日期。 |
| M2 檢索 | 用真實索引驗證專利號、繁中關鍵字和語意檢索。結果保留可取得的名稱、公開／公告號、申請人、日期、摘要、IPC 與官方來源。 |
| M3 分析 | 依使用者描述提取候選技術特徵。保留原始查詢及擴展的中英文詞與候選分類，透過全文與向量結果融合、去重和重排序。比對顯示「有明確證據、部分符合、未找到證據、不確定」，前兩者須有可核對的原文引文與定位，後兩者交代已檢查範圍及限制。 |
| M4 操作 | 使用者可編輯、新增、刪除特徵及調整重要程度，查看排序原因與原始文件、請求項或段落，並在研究專案保存搜尋、候選專利和筆記。以真實 API 驗證瀏覽器流程及載入、空結果與錯誤狀態。 |
| M5 報告與隱私 | 從已保存的檢索匯出 PDF，包含策略、資料涵蓋範圍、候選文件、比對證據及限制。驗證未公開構想與研究紀錄的存取控制，並揭露模型供應商的資料保留條件。 |

分類建議須標明候選，文件的 CPC 欄位只有在來源提供時才呈現。語料中未找到某項組合，只代表已檢查的內容未找到證據。報告不得據此判定新穎性、可專利性或侵權。
