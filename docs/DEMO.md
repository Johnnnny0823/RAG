# 官方語料展示

此流程使用 TIPO 第 024019 與 053028 期的固定官方語料。示範選用公開的光硬化樹脂技術描述，可換成其他研究題目。樣本有 117 個文件版本，搜尋結果受此範圍限制。[來源與欄位](DATA_SOURCES.md)

## 準備

1. 依 [開發環境](SETUP.md) 建立 Python 環境及專用 Compose 專案。若使用正式前端，依 [靜態部署](SETUP.md#靜態前端部署) 啟動並記下 Web 連接埠。
2. 依 [固定官方樣本](TESTING.md#自動建立固定官方樣本) 匯入語料。首次需要取得官方原檔，已有核對過的檔案可加 `--offline`。若只驗證號碼與詞彙，加入 `--skip-semantic`。
3. 自然語言研究流程需要 Qwen 嵌入及分析模型。在啟動 API 與背景工作前設定 [嵌入模型](SETUP.md#m2-本機語意索引) 和 [分析模型](SETUP.md#m3-本機技術特徵驗收)，再依固定樣本步驟建立向量索引。

## 先確認官方文件

在研究頁的**專利號碼查詢**選擇申請號並輸入 `114106690`。開啟公開 `202640162` 與公告 `I941082`，逐份查看標題、請求項和來源。兩份文件均涉及動態導通電阻，但保有各自的文件階段、原文定位和來源雜湊。

## 從構想到報告

1. 使用測試帳號登入，可先建立研究專案。輸入「我想以可見長波光照射，在較低溫下使樹脂接著劑硬化，用於半導體元件組裝。希望比對光源波長、樹脂配方與使用方法。」
2. 選擇 **AI 拆解技術特徵**。檢查模型提出的技術特徵，保留或新增「光硬化性樹脂組成物」，繁中檢索詞填入相同詞彙。可使用 IPC `C08F` 縮小範圍。
3. 選擇 **搜尋並保存**。要縮小到固定案例，可選文件種類「公開」並填入申請人「九州大學」。工作完成後，從結果開啟公開 `202639611` 的全文版本，查看摘要、排序欄位與請求項。
4. 選擇 **比對並保存證據**。展開 **原文定位**，核對引文、請求項或說明書位置、原始檔 SHA-256 及官方來源。判定只涵蓋實際檢查的原文。
5. 選擇 **匯出 PDF 報告**。下載後核對構想、特徵、索引涵蓋範圍、候選專利和官方引文。登出後重新登入，可從搜尋歷史開啟同一份保存紀錄。

## 自動重現

準備固定語料與模型後，將下例的 URL 改成已啟動的隔離 Web 入口。測試會自行建立及清理帳號，並將驗證過的 PDF 留在本機 Playwright 測試輸出目錄。

```powershell
$env:PATENTSCOPE_E2E_TIPO = '1'
$env:PATENTSCOPE_E2E_URL = 'http://127.0.0.1:18125'
$env:PATENTSCOPE_TEST_PYTHON = (Resolve-Path .venv/Scripts/python.exe).Path
npm run test:e2e --prefix apps/web -- tipo-research.spec.ts
```

模型輸出與排行可能隨模型版本、語料與查詢改變。展示記錄可供初步先前技術調查，正式法律判斷仍須依完整資料核對。
